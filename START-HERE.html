คู่มือเว็บไซต์ MASTER DIGITAL

อ่านทีละข้อ ทำตามทีละขั้น ไม่ต้องมีความรู้คอมพิวเตอร์มาก่อน

ส่วนที่ 1 · ไฟล์ในชุดนี้มีอะไรบ้าง

ไฟล์คืออะไรต้องแก้ไหม
content.jsข้อมูลทั้งหมดบนเว็บ: ชื่อโปรแกรม ราคา สถานะ เวอร์ชัน FAQ ช่องทางติดต่อแก้ไฟล์นี้ไฟล์เดียว
styles.cssสีและหน้าตาเฉพาะตอนอยากเปลี่ยนสี (ส่วนที่ 6)
index.htmlหน้าแรกไม่ต้อง
product.htmlหน้ารายละเอียดของแต่ละโปรแกรมไม่ต้อง
script.jsตัวดึงข้อมูลจาก content.js มาแสดงไม่ต้อง
server.js, package.jsonตัวเปิดเว็บบน Railwayไม่ต้อง
assets/โฟลเดอร์รูป: โลโก้ QR LINE และรูปหน้าจอโปรแกรมใส่รูปเพิ่มได้

ส่วนที่ 2 · ดูหน้าเว็บบนคอมพิวเตอร์ก่อน

  1. คลิกขวาไฟล์ MASTER-DIGITAL.zip ที่ดาวน์โหลดมา เลือก Extract All… (แตกไฟล์)
  2. เลือกที่เก็บเป็น Desktop แล้วกด Extract จะได้โฟลเดอร์ Desktop\MASTER-DIGITAL
  3. เปิดโฟลเดอร์นั้น ดับเบิลคลิกไฟล์ index.html เว็บจะเปิดในเบราว์เซอร์
  4. ลองกดดูการ์ดโปรแกรม ปุ่มหมวดหมู่ และเลื่อนดูทั้งหน้า

ส่วนที่ 3 · ส่งไฟล์ขึ้น GitHub

  1. เข้า github.com แล้วล็อกอินบัญชี kiattisaklug-create
  2. กดปุ่ม + มุมขวาบน เลือก New repository
  3. ช่อง Repository name พิมพ์ MASTER-DIGITAL
  4. เลือก Public แล้วกด Create repository สีเขียวด้านล่าง
  5. ในหน้าใหม่ที่ขึ้นมา กดลิงก์ uploading an existing file
  6. เปิดโฟลเดอร์ Desktop\MASTER-DIGITAL กด Ctrl + A (เลือกทุกไฟล์และโฟลเดอร์ assets)
  7. ลากทั้งหมดไปวางในกรอบบนหน้า GitHub รอจนรายชื่อไฟล์ขึ้นครบ
  8. เลื่อนลงล่าง กดปุ่ม Commit changes สีเขียว
  9. ตรวจว่าหน้า repo มีไฟล์ index.html และโฟลเดอร์ assets อยู่ชั้นนอกสุด (ไม่ได้ซ้อนอยู่ในโฟลเดอร์ MASTER-DIGITAL อีกชั้น)
ถ้าเห็นไฟล์ซ้อนอยู่ในโฟลเดอร์อีกชั้น แปลว่าลากโฟลเดอร์ทั้งก้อนไปแทนที่จะลากไฟล์ข้างใน ให้ลบ repo แล้วทำข้อ 2–8 ใหม่ โดยลากเฉพาะของข้างในโฟลเดอร์

ส่วนที่ 4 · เปิดเว็บจริงบน Railway

  1. เข้า railway.com ล็อกอิน แล้วเปิดโปรเจกต์ของคุณ
  2. กดปุ่ม + Create (หรือ + New) มุมขวาบน เลือก GitHub Repo
  3. เลือก kiattisaklug-create/MASTER-DIGITAL (ถ้าไม่เห็น ให้กด Configure GitHub App แล้วติ๊กอนุญาต repo นี้)
  4. Railway จะเริ่มสร้างเว็บเอง รอจนกล่องขึ้นคำว่า Active หรือ Success สีเขียว (ประมาณ 1–3 นาที)
  5. คลิกกล่องบริการนั้น ไปแท็บ Settings เลื่อนหาหัวข้อ Networking
  6. กด Generate Domain ถ้าระบบถามเลข Port ให้พิมพ์ 8080 แล้วกดยืนยัน
  7. จะได้ลิงก์หน้าตาประมาณ master-digital-production.up.railway.app กดเปิดได้เลย นี่คือเว็บจริงของคุณ
หลังจากนี้ ทุกครั้งที่คุณแก้ไฟล์บน GitHub แล้วกด Commit, Railway จะอัปเดตเว็บให้เองภายใน 1–2 นาที ไม่ต้องทำส่วนที่ 4 ซ้ำอีก

ส่วนที่ 5 · แก้ข้อมูลบนเว็บด้วยตัวเอง

วิธีเปิดไฟล์มาแก้ (ใช้ทุกครั้ง)

  1. เข้า github.com/kiattisaklug-create/MASTER-DIGITAL
  2. คลิกไฟล์ content.js
  3. กดรูปดินสอ ✏️ มุมขวาบนของไฟล์ (Edit this file)
  4. แก้ข้อความที่ต้องการ (ดูตัวอย่างด้านล่าง)
  5. กด Commit changes… สีเขียวมุมขวาบน แล้วกด Commit changes อีกครั้ง
  6. รอ 1–2 นาที เปิดเว็บแล้วกด Ctrl + F5 เพื่อดูของใหม่

ตัวอย่าง: ใส่ราคา

หาบรรทัดของโปรแกรมนั้น เปลี่ยนคำว่า สอบถามราคา เป็นราคาจริง

{ name: "Lite", price: "สอบถามราคา", note: "เริ่มต้นสำหรับคลินิกขนาดเล็ก" },
                     ↓ เปลี่ยนเป็น
{ name: "Lite", price: "4,900 บาท / เดือน", note: "เริ่มต้นสำหรับคลินิกขนาดเล็ก" },

ตัวอย่าง: เปลี่ยนสถานะ

ช่อง status ใส่ได้ 3 แบบ: "ready" = พร้อมใช้งาน, "demo" = เปิดทดลอง DEMO, "soon" = กำลังพัฒนา

ตัวอย่าง: อัปเดตเวอร์ชันใหม่

  1. แก้ version: "V1" เป็น version: "V1.1"
  2. ในช่อง changelog เพิ่มบรรทัดใหม่ไว้บนสุด (ของใหม่อยู่บน):
changelog: [
  { version: "V1.1", date: "พ.ย. 2569", text: "เพิ่มโมดูลนัดหมายคนไข้" },
  { version: "V1",   date: "ก.ย. 2569", text: "เปิดตัวเว็บไซต์และเปิดให้คลินิกทดลองใช้ DEMO" }
]

ตารางเวอร์ชันล่าสุดในหน้าแรกจะเปลี่ยนตามเอง

ตัวอย่าง: ซ่อนโปรแกรมชั่วคราว

ในโปรแกรมนั้น เพิ่มบรรทัด hidden: true, ใต้บรรทัด id: ... จะหายจากเว็บทุกจุด ลบบรรทัดนี้ออกเพื่อให้กลับมา

ตัวอย่าง: เพิ่มโปรแกรมใหม่

  1. ใน content.js เลือกโปรแกรมที่คล้ายกันที่สุด คลุมตั้งแต่ { บรรทัด id: ลงไปจนถึง }, ปิดท้าย แล้วกด Ctrl + C
  2. คลิกต่อท้าย }, ของโปรแกรมตัวสุดท้าย กด Enter แล้ว Ctrl + V
  3. แก้ id ให้ไม่ซ้ำกับตัวอื่น (ภาษาอังกฤษตัวเล็ก ไม่เว้นวรรค เช่น "new-app") แล้วแก้ข้อความอื่นตามต้องการ
  4. ตรวจว่าตัวสุดท้ายในรายการไม่มี , ต่อท้ายก็ได้ มีก็ได้ แต่ระหว่างโปรแกรมทุกตัวต้องมี , คั่น

หน้าปัดทองในหน้าแรกจะเพิ่มจุดของโปรแกรมใหม่ให้เอง

ตัวอย่าง: ใส่รูปหน้าจอโปรแกรม

  1. เตรียมรูปเป็น .jpg หรือ .png ตั้งชื่อเป็นภาษาอังกฤษ เช่น aestiva.jpg (ตรวจว่าไม่มีข้อมูลคนไข้จริงในรูป)
  2. บน GitHub เปิดโฟลเดอร์ assets → products กด Add file → Upload files ลากรูปวาง กด Commit
  3. ใน content.js ของโปรแกรมนั้น แก้ image: "" เป็น image: "assets/products/aestiva.jpg"

ตัวอย่าง: ใส่ช่องทางติดต่อเพิ่ม

ในหัวข้อ contact ใส่เบอร์โทร อีเมล หรือลิงก์ TikTok / Instagram ในเครื่องหมายคำพูด ช่องที่ว่างไว้จะไม่แสดงบนเว็บ

ส่วนที่ 6 · เปลี่ยนสีทั้งเว็บ

  1. บน GitHub เปิดไฟล์ styles.css กดดินสอ ✏️
  2. ด้านบนสุดมีกล่อง :root รวมสีทั้งหมด เช่น --gold: #C9A55C;
  3. เปลี่ยนรหัสสีหลัง # (หารหัสสีได้จาก Google คำว่า "color picker")
  4. กด Commit changes

ส่วนที่ 7 · ถ้าแก้แล้วเว็บพังหรือว่างเปล่า

  1. ส่วนใหญ่เกิดจากเครื่องหมาย " , { } หายไปหนึ่งตัว
  2. บน GitHub เปิด content.js กดปุ่ม History มุมขวาบน
  3. กดเวอร์ชันก่อนหน้าที่ยังดีอยู่ กดปุ่ม … → View file → กดไอคอนคัดลอก (Copy raw file)
  4. กลับมาแก้ content.js ปัจจุบัน ลบของเดิมทั้งหมด (Ctrl + A แล้ว Delete) วางของที่คัดลอก (Ctrl + V) แล้ว Commit
เคล็ดลับ: ก่อนแก้ครั้งใหญ่ ให้ copy ข้อความทั้งไฟล์ content.js ไปเก็บใน Notepad ไว้ก่อนเสมอ

ส่วนที่ 8 · หน้าติดต่อและหน้านโยบาย

เว็บมี 4 หน้า: ติดต่อเรา (contact.html), นโยบายคืนเงิน (refund.html), เงื่อนไขการใช้บริการ (terms.html), นโยบายความเป็นส่วนตัว (privacy.html) ลิงก์อยู่ท้ายเว็บทุกหน้า

  1. ข้อมูลธุรกิจ (ชื่อ ที่อยู่ อีเมล เบอร์โทร เวลาทำการ จำนวนวันคืนเงิน) แก้ที่ไฟล์ business.js ไฟล์เดียว ทุกหน้าจะเปลี่ยนตาม
  2. ช่องที่ยังว่าง เว็บจะซ่อนแถวนั้นให้เอง
  3. เครื่องที่เคยเปิด ?notrack=1 จะเห็นแถบสีเหลืองบอกว่ายังกรอกอะไรไม่ครบ คนทั่วไปไม่เห็น
  4. แก้ข้อความนโยบาย: เปิดไฟล์ .html ของหน้านั้นบน GitHub แก้เฉพาะข้อความระหว่าง <p> กับ </p> หรือ <li> กับ </li>
  5. ทุกครั้งที่แก้นโยบาย เปลี่ยน effectiveDate ใน business.js เป็นวันที่ใหม่
